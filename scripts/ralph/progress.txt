## Codebase Patterns
- Types are in `src/types/index.ts` (not `src/types.ts`)
- Local tsc binary: `node_modules/.bin/tsc --noEmit`
- `@/` path alias maps to `src/`
- `config.websocketUrl` from `src/config/env.ts` is the toggle between local and WS mode
- For timer-based animation removal in tests, use `vi.useFakeTimers()` + `act(() => vi.advanceTimersByTime(N))` — CSS `animationend` events don't fire in JSDOM
- CSS keyframes can be injected via a `<style>` tag with a const string; use CSS custom properties (`--dx`, `--dy`) on each element for per-instance values in keyframes
