## Codebase Patterns
- Types live in `src/types/index.ts` (imported as `@/types`)
- `storage` utility in `src/lib/storage.ts` wraps localStorage; use it for all read/write in local transport
- `config.websocketUrl` in `src/config/env.ts` controls transport mode (empty = localStorage)
- Transport test seam: `setTransport()` / `getTransport()` in `src/lib/transport.ts`
- Tests use `vi.useFakeTimers()` for interval-based logic; always call `vi.useRealTimers()` in afterEach
- `storage.generateId()` available for random ID generation
- Component tests: use `setTransport(mockTransport)` in beforeEach / `setTransport(null)` in afterEach — no need to mock storage or api
- `useRef(getTransport())` in hooks captures transport once on mount to avoid creating multiple WS instances
- `createSession` interface accepts `sessionId` as first param — caller pre-generates it and can immediately invoke callbacks
